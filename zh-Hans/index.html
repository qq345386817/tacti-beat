TactiBeat 能做什么

保存式文件分析

导入音频或视频，在设备上分析波形和震动事件，并保存结果以便快速重播。

实时声音

用麦克风把周围声音转成实时 Core Haptics 触觉活动。

音频流 URL

把直接音频流 URL 预览成低频、节奏和亮度触觉活动。

使用场景

触觉音乐 App

把音乐和视频转换成 iPhone 上的触觉节奏。

音乐震动 App

感受节拍、低频脉冲和节奏，而不是连续嗡振。

实时声音触觉

用麦克风或直接音频流 URL 生成实时触觉活动。

适合节奏清晰的音频

带有打击乐、重拍、停顿和明显能量变化的素材通常效果最好。流媒体适用于直接音频流 URL，不支持受保护的音乐服务流。震动无法忠实保留音高、歌词或音色，因此 TactiBeat 重点呈现时序、脉冲和节奏感。
